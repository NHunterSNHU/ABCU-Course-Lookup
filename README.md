# ABCU-Course-Lookup

The main problem I solved when completing the projects in this course was learning how to build software effectively using efficient data structures and modular algorithms. For each problem, I first needed to look at what the whole project would look like when completed. This meant determining what functions would be needed, what data would need to be stored, and what steps the program would need to go through. I learned to evaluate the requirements first and then choose an appropriate data structure rather than defaulting to one. For example, I learned that binary trees are very efficient for sorting and iterating through data in alphabetical order compared to many of the other data structures we reviewed. Using binary trees was also a great example of how recursive methods can simplify and modularize functions.

The main roadblock I overcame was learning all the different data structures and the functions associated with each one. Using each data structure in practice and learning what made each one better than the others in different situations was the best way for me to understand how and when to use them.

I also expanded my approach to designing software by learning to take a bigger-picture view of a project and develop pseudocode before jumping into coding. It helps to break larger problems into smaller functions and determine how those functions would work together before implementing them. This has evolved the way I write programs because I can better plan ahead instead of immediately starting to code and trying to figure out what the final product will look like during development. Planning the structure of a program first has saved me time and helped me develop software that is more effective.

This approach has also improved the way I write programs to make them more maintainable, readable, and adaptable. By using modular functions and organizing my code around each function, I can make software easier to understand and modify. I have also learned to avoid unnecessary duplication by creating reusable functions when the same logic is needed in multiple places. This makes it easier to make changes because I can update one function instead of changing the same logic throughout the program. Overall, this course has taught me to think about the structure of a program before writing the code, which has made my development process much more organized!
